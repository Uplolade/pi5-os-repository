# Raspberry Pi 5 OS Repository

Custom Raspberry Pi Imager catalog synchronized with the official Armbian catalog.

## Raspberry Pi Imager 2.x

Open App Options → Content Repository → Edit → Use custom URL and paste:

`https://raw.githubusercontent.com/Uplolade/pi5-os-repository/main/os_list.json`

## Included Armbian images

- Resolute KDE Plasma Desktop 26.5.1
- Resolute Gnome Desktop 26.5.1
- Resolute Minimal 26.5.1
- Trixie Minimal 26.5.1

Catalog source: https://github.armbian.com/rpi-imager.json
